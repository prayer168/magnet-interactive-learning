# 磁鐵的祕密

「磁鐵的祕密」是給國小三年級自然科學使用的互動式數位教材。

## 教材資訊

- 適用對象：國小三年級
- 科目：自然科學
- 學習時間：40分鐘
- 教材模式：引導模式
- 目前版本：v1.0.0
- GitHub Pages：https://prayer168.github.io/magnet-interactive-learning/

## 學習目標

- 能說出磁鐵能吸引含鐵的物體，並判斷哪些物品會被吸引。
- 能說出磁鐵有 N、S 兩極，兩端磁力最強，且同極相斥、異極相吸。
- 能舉出磁鐵在生活中的應用（指南針、冰箱貼、馬達、磁浮列車等）。

## 主題段落

1. 磁力的探討
2. 磁鐵的特性
3. 磁鐵與生活

## 頁籤內容

學習任務、原理探索、互動實驗、動畫模擬、生活應用、闖關大挑戰、自學資源（共七頁籤）。
