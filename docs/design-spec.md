# 設計規格：磁鐵的祕密

- 版本：v1.0.0
- 日期：2026-06-22
- 適用對象：國小三年級 · 自然科學
- 學習時間：40分鐘
- 教材模式：引導模式
- 視覺風格：清爽、活潑、紅藍磁極對比

## 主題段落

1. 磁力的探討
2. 磁鐵的特性
3. 磁鐵與生活

## 頁籤架構

1. 學習任務
2. 原理探索

7. 自主學習

## 互動與動畫設計

- 動畫採分階段狀態切換，避免所有視覺元素同時動作。
- 動畫與說明文字分區呈現，避免文字疊在動態圖形上。
- 全站尊重 `prefers-reduced-motion`，使用者關閉動態時自動停用動畫。

| 頁籤 | 互動／動畫 | 學習重點 |
| ---- | ---------- | -------- |
| 學習任務 | SVG 迴紋針被磁鐵一吸一放（CSS 循環動畫） | 引起動機：磁鐵能隔空吸鐵 |
| 原理探索 | N/S 磁極與流動的磁力線（虛線位移動畫） | 兩極、磁力線、磁極最強 |
| 互動實驗 | 滑桿控制磁鐵與迴紋針距離，即時改變吸力條與文字 | 距離越近吸力越強 |
| 動畫模擬 | 三階段：鐵釘內小磁針由亂到齊，最後吸住迴紋針 | 磁化原理 |
| 生活應用 | 8 張可點按卡片（指南針、冰箱貼、磁浮列車…） | 磁鐵的生活應用 |
| 闖關大挑戰 | 12 題即時回饋、計分、可重來 | 形成性評量 |
| 自學資源 | 因材網、PhET、均一影音與互動連結（附來源與檢核日） | 延伸自學 |
